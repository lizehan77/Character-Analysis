# 角色分析 (Character Analysis) - AI 军师系统

基于 PyQt5 和 本地大模型 (或云端 API) 构建的聊天分析工具。帮助你分析聊天对象的人物画像、推演实时回复、并预测关系好感度。

> ⚠️ **免责声明**：本工具所有数据均需用户**手动导入**（复制粘贴聊天记录），不直接读取、破解或解密任何微信本地数据库。所有 AI 生成的内容仅供参考与娱乐，请勿用于非法用途。

## ✨ 核心功能
- **双模驱动**：支持本地运行量化模型（默认支持 Qwen2-7B-Int4），也支持接入云端 API（如 DeepSeek、通义千问）。
- **人物画像**：增量合并对话，自动生成结构化的卡片式人物画像。
- **实时军师**：分析对方当前情绪，提供高情商回复话术。
- **模拟对话**：基于人物画像，扮演对方与你进行聊天测试。
- **关系扫描**：读取全量记录，预测 0-100% 的好感度，并绘制历史趋势折线图。
